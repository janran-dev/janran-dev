### 📌 Featured Open-Source Projects

#### 🧬 [GenAI Toolbox](https://github.com/janran-dev/genai-toolbox)
> **Synthetic Health Data Engine & Generative AI Suite**
* Generative ML framework for privacy-preserving synthetic health data generation (tabular patient data & time-series ECG generation using CTGAN and modern diffusion architectures).
* Includes a built-in RAG (Retrieval-Augmented Generation) assistant for dataset exploration and synthetic data validation.
* **Stack:** `Python` • `PyTorch` • `Streamlit` • `RAG / LLMs`

#### 🌤️ [Weather Application](https://github.com/janran-dev/Weather-Application)

* Desktop application following strict MVC architecture, integrating OpenWeatherMap and GeoNames APIs for high-accuracy location search and weather forecasting.
* Features custom FXML layouts, dual unit systems (Metric/Imperial), persistent JSON local storage, and automated TestFX UI testing suite.
* **Stack:** `Java` • `JavaFX` • `REST API` • `Gson` • `TestFX`
